# `tcpdump`

## 1.基本介绍

`tcpdump` 是 Linux 下功能强大的命令行抓包工具，支持过滤规则，可直接查看包内容。

`tcpdump` 本身不能解析到应用层后自动拆头

## 2.确认安装

  ### 1.先查有没有
```shell
  which tcpdump
  tcpdump --version
```

### 2.没有则安装

```shell
  apt-get install tcpdump   # Debian 系
  opkg install tcpdump      # OpenWr
```

## 3.基本抓包命令

### 1.默认抓包

```shell
# 抓所有 TCP 包，保存到文件
tcpdump -i eth0 tcp -w /tmp/capture.pcap

# 捕获所有网络接口的数据包（需要root权限）
sudo tcpdump -i any

# 捕获指定接口（如eth0）的数据包
sudo tcpdump -i eth0

# 捕获指定数量的包（如10个）后退出
sudo tcpdump -i eth0 -c 10

# 保存捕获的包到文件（后续可用Wireshark分析）
sudo tcpdump -i eth0 -w capture.pcap

# 读取保存的包文件并显示内容
tcpdump -r capture.pcap
```

### 2.条件过滤

#### 1.过滤端口

```shell
# 指定端口
tcpdump -i eth0 port 8080 -w /tmp/capture.pcap
```

#### 2.过滤主机

```shell
# 指定主机
tcpdump -i eth0 host 192.168.1.100 -w /tmp/capture.pcap

# 只看本机 → 远程（src 是本机）
tcpdump -i eth0 'src 192.168.191.223 and dst 219.142.255.18' -w out.pcap

# 只看远程 → 本机（dst 是本机）
tcpdump -i eth0 'src 192.168.1.100 and dst 192.168.1.50' -w in.pcap

# 用 src/dst 简写，不指定另一端也行
tcpdump -i eth0 'src 192.168.1.50 and port 8080'    # 所有本机发出的
tcpdump -i eth0 'dst 192.168.1.50 and port 8080'    # 所有发给本机的
```

#### 3.组合过滤

```shell
# 组合过滤：本机 192.168.1.50 的 8080 端口
tcpdump -i eth0 'tcp and port 8080 and host 192.168.1.100' -w /tmp/capture.pcap
```

### 3.数量大小

```bash
# 抓指定数量后自动停止（防止文件太大）
tcpdump -i eth0 tcp -c 1000 -w /tmp/capture.pcap

# 限制单个包大小（snaplen，单位字节），节省空间
tcpdump -i eth0 tcp -s 256 -w /tmp/capture.pcap

# 实时看（不写文件），加 -v/-vv  verbose，冗余的,详情的，-n 不做 DNS 反查
tcpdump -i eth0 tcp -n -vv 
```

### 4.显示包内容

```bash
# 以ASCII码显示包内容（-A）
sudo tcpdump -i eth0 -A

# 以十六进制和ASCII码显示包内容（-X）
sudo tcpdump -i eth0 -X

# 显示更详细的协议信息（-v 或 -vv 或 -vvv）
sudo tcpdump -i eth0 -vvv -X
```

### 5.过滤规则

```bash
# 捕获特定端口（如80端口）的包并显示内容
sudo tcpdump -i eth0 port 80 -X

# 捕获特定IP（如192.168.1.100）的包并显示内容
sudo tcpdump -i eth0 host 192.168.1.100 -A

# 捕获TCP协议且目标端口为443的包
sudo tcpdump -i eth0 tcp dst port 443 -vvv -X
```

### 6.常用过滤条件

  #### 1.只看 `SYN/ACK/FIN` 等控制包

```shell
tcpdump -i eth0 'tcp[tcpflags] & (tcp-syn|tcp-fin|tcp-rst) != 0' -w /tmp/capture.pcap
```

#### 2.排除 `SSH `流量（避免抓到自己）

```shell
tcpdump -i eth0 tcp and not port 22 -w /tmp/capture.pcap
```

#### 3.抓特定 `IP` 段

```shell
 tcpdump -i eth0 'net 192.168.1.0/24' -w /tmp/capture.pcap
```

# `Wireshark` 

## 1.打开文件

```cmd
wireshark capture.pcap
```

## 2.过滤

`Wireshark`顶部过滤栏输入：

```shell
tcp.port == 8080                     # 只看某个端口
ip.addr == 192.168.1.50              # 只看某个 IP
tcp.flags.syn == 1                   # 只看 SYN 包
tcp.analysis.retransmission          # 只看重传包
tcp.analysis.lost_segment            # 只看丢包
frame.time_relative > 5              # 只看 5 秒后的包
```

##  3.右键菜单

```shell
  Follow → TCP Stream   # 看一次完整 TCP 会话，纯文本/hex 展示对话内容
  Decode As             # 如果端口识别错协议，手动修正
  Mark/Unmark Packet    # 标记可疑包
```

##   4.统计菜单

```shell
  Statistics → IO Graph         # 流量图，看吞吐量趋势
  Statistics → TCP Stream Graphs → Time-Sequence (Stevens)  # 看 TCP 序列号和重传
  Statistics → Flow Graph       # 连接流程图，看握手/挥手顺序
  Statistics → Protocol Hierarchy # 各协议占比
  Analyze → Expert Information  # 自动诊断：重传、乱序、零窗口…
```

##  5.`TCP`流时序图

主要用于查网络性能问题，选中一个包 → Statistics → TCP Stream Graphs → Time-Sequence (Stevens)

  - X 轴 = 时间，Y 轴 = TCP Sequence 号
  - 正常情况：一条斜向上的直线
  - 断崖式变平 = 有停顿/超时
  - 看到竖线下垂 = 可能重传

## 6.常见问题排查

|               现象               |            `Wireshark`表现             |                  可能原因                   |
| :------------------------------: | :------------------------------------: | :-----------------------------------------: |
|             连接不上             |         多次`SYN`，无`SYN-ACK`         |       服务没启动 / 防火墙 / 路由不通        |
|        `SYN`发出收到`RST`        |            黑底红字的`RST`             |            端口未监听 / 连接被拒            |
| `SYN`发出收到 `ICMP unreachable` |                `ICMP`包                |            路由不通或主机不可达             |
|              传输慢              |            间隔大、窗口变小            |           应用层读得慢 / 带宽瓶颈           |
|             大量重传             |    红色背景的 [TCP Retransmission]     |       网络丢包 / 网线 / `WiFi` 信号差       |
|            连接被重置            |            `RST` after data            | 程序崩溃 / close() 时有未读数据 / SO_LINGER |
|            大量乱序包            | [`TCP Out-Of-Order`] / [`TCP Dup ACK`] |      路由路径不一致 / 网卡 multi-queue      |
|              零窗口              |           [TCP Zero Window]            |       接收方缓冲区满，应用层处理太慢        |
|           半关闭半吊子           |        只有 FIN 没有 `FIN-ACK`         |         一端 close 后对端 crash 了          |

# `tshark`

## 1.基本介绍

`tshark` 是 `wireshark` 的命令行工具，功能类似 `tcpdump` 但支持更多协议解析。

## 2.基本用法

```bash
# 捕获eth0接口的包并显示详细内容
sudo tshark -i eth0

# 以JSON格式显示包内容（便于解析）
sudo tshark -i eth0 -T json

# 显示HTTP请求的URL和内容
sudo tshark -i eth0 -Y "http.request" -T fields -e http.request.uri -e http.file_data

-T pdml|ps|psml|json|jsonraw|ek|tabs|text|fields|?
                           format of text output (def: text)
                           
-e <field>               field to print if -Tfields selected (e.g. tcp.port,
                           _ws.col.Info)
                           this option can be repeated to print multiple fields
                           
-E<fieldsoption>=<value> set options for output when -Tfields selected:
     bom=y|n               print a UTF-8 BOM
     header=y|n            switch headers on and off
     separator=/t|/s|<char> select tab, space, printable character as separator
     occurrence=f|l|a      print first, last or all occurrences of each field
     aggregator=,|/s|<char> select comma, space, printable character as
                           aggregator
     quote=d|s|n           select double, single, no quotes for values
```

## 3.显示应用层内容

```bash
# 显示发送的ASCII文本数据
sudo tshark -i eth0 -Y 'tcp.dstport == 8080 and ip.dst == 192.168.1.100' -T fields -e data.text
#如 Hello, Server! This is a test message.

# 显示十六进制数据
sudo tshark -i eth0 -Y 'tcp.dstport == 8080 and ip.dst == 192.168.1.100' -T fields -e data
#如68 3a 00 43 05 06 05 04 03 02 01 10 e0 d4 09 07 00 f2 09 02 00 03 02 08 01 00 00 78 00 64 19 68 01 00 15 08 25 20 68 14 0d 33 33 38 37 35 33 33 33 34 33 33 33 35 f9 16 00 4b d1 16

# 应用层 payload（hex 格式）
tshark -i eth0 -T fields -e tcp.payload

# 加过滤条件
tshark -i eth0 -T fields -e tcp.payload -f "port 8080"

# 解码成 ASCII（后面再 pipe 转可读文本）
tshark -i eth0 -T fields -e tcp.payload -f "port 8080" | while read hex; do echo "$hex" | xxd -r -p; echo; done
```
