# 传统拨号（`PPP/PPPoE`）

## 1.定义

- 通过调制解调器（Modem）将数字信号转换为模拟信号，通过电话线或无线链路建立连接。
- **典型技术**：`PPP`（点对点协议）、`PPPoE`（以太网上的 `PPP`）。

## 2.常见场景

- **家庭宽带**：早期 `ADSL` 宽带通过 `PPPoE` 拨号（如 “宽带连接”）。
- **工业设备**：电力抄表设备通过 `GPRS` 模块 + `PPP` 协议连接运营商网络。

## 3.生活例子

- 家中老路由器需输入用户名密码 “拨号上网”（`PPPoE`）。
- 智能电表通过 `GPRS` 模块（如 SIM 卡）连接电力公司服务器。

# ` GPRS`（通用分组无线服务）

## 1.定义

- `2.5G`移动网络技术，基于`GSM`，支持分组交换数据传输（按流量计费）。
- **特点**：速度慢（最高`1115kbps`），覆盖广，适合小数据量传输。

## 2.常见场景

- **物联网设备**：共享单车定位模块、远程监控摄像头。
- **工业数据传输**：早期电力抄表、`POS`机刷卡实时联网。

## 3.生活例子

- 共享单车内置`GPRS`模块，每次扫码解锁时通过运营商网络上报位置。
- 加油站`POS`机通过`GPRS`实时传输交易数据。

#  以太网拨号（`DHCP / 静态 IP`）

## 1.定义

- 通过有线以太网卡连接局域网或互联网，通常采用` DHCP `自动获取 `IP`，或手动配置静态` IP`。
- **特点**：高速稳定（百兆 / 千兆），需物理网线连接。

## 2.常见场景

- **家庭 / 企业网络**：电脑、智能电视通过网线连接路由器。
- **工业控制**：`PLC`（可编程逻辑控制器）通过以太网连接监控系统。

## 3.生活例子

- 台式机通过网线连接路由器，直接访问互联网。
- 公司服务器通过光纤接入机房交换机，使用静态` IP `联网。

# `4G/5G`蜂窝网络

## 1.定义

- 第四 / 五代移动通信技术，提供高速数据传输（`4G` 理论峰值 `1Gbps`，`5G` 可达 `10Gbps`）。
- **特点**：无需物理线路，覆盖广，支持移动场景。

## 2.常见场景

- **智能手机**：浏览网页、视频通话、在线游戏。
- **物联网**：智能穿戴设备、自动驾驶车辆联网。

## 3.生活例子

- 手机开启` 4G/5G`，无需 `Wi-Fi` 即可刷短视频。
- 特斯拉汽车通过 `4G/5G` 实时上传行驶数据到云端。

# 联系与区别总结

| 维度         | 传统拨号（`PPP`）           | `GPRS`                  | 以太网拨号                      | `4G/5G`蜂窝网络             |
| ------------ | --------------------------- | ----------------------- | ------------------------------- | --------------------------- |
| **传输介质** | 电话线 / 无线模块           | 移动网络基站            | 以太网线                        | 无线基站                    |
| **典型速率** | 几十`kbps~1Mbps`            | 最高`115kbps`           | 百兆 / 千兆                     | `4G: 100Mbps+` `5G: 1Gbps+` |
| **应用场景** | 老旧宽带、工业设备          | 低带宽物联网            | 固定设备高速联网                | 移动设备、高速移动场景      |
| **连接方式** | 需拨号认证（用户名 / 密码） | 自动连接（依赖 SIM 卡） | `DHCP` 自动获取 `IP` 或静态配置 | 自动连接（依赖 SIM 卡）     |
| **生活例子** | 老路由器`ADSL `拨号         | 共享单车定位            | 台式机网线联网                  | 手机 `4G/5G` 上网           |

```c++

//---通信方式----
enum eCOMMTYPE
{
    eComNULL,
    //无线通信方式
    eComNET,//通常指基于移动网络的通用数据通信（如 GPRS、4G/5G 等），通过分组交换网络传输数据，适用于广域无线联网（如智能电表远程抄表）。
    eComSMS,//基于短信服务（SMS）的通信，用于发送短文本指令或报警信息（如设备故障时通过短信通知管理员）。
    eComAwake,//唤醒通信（如通过特定信号激活设备从休眠状态进入工作状态），常见于低功耗设备（如物联网传感器，平时休眠，被唤醒后传输数据）。
    eComCSD,//电路交换数据（Circuit Switched Data），基于传统电话网络的有线 / 无线数据传输（类似拨号上网，已较少使用）
    eComDTMF,//双音多频（Dual-Tone Multi-Frequency）信号通信，通过电话按键音传输简单指令（如早期远程控制设备）。
    eWireless230M,//230MHz 无线通信，一种专用无线频段通信方式，常用于电力、水利等行业的短距离无线数据传输（如变电站设备间的本地通信）。
    
    //有线通信
    eComRS232,//基于 RS232 串行接口的通信，用于设备与本地终端的近距离有线连接（如调试时通过串口连接电脑配置参数）。
    eEthernet,//以太网通信（非标准适配），通常指自定义的以太网协议实现，适用于特定设备的局域网连接。
    eEthernet_std,//标准以太网通信，遵循 IEEE 802.3 标准，通过 TCP/IP 协议传输数据（如工业设备通过网线连接到路由器）。
    eOnlineSection,//在线时段通信，指设备仅在预设的 “在线时段” 内启用通信（如电力设备在凌晨低谷期集中上传数据，节省流量）。
    ePppoe,//基于以太网的点对点协议（Point-to-Point Protocol over Ethernet），常用于宽带拨号上网（如通过调制解调器连接到运营商网络）。
    eEpon,//以太网无源光网络（Ethernet Passive Optical Network），通过光纤传输数据，适用于高带宽、长距离的有线通信（如小区宽带、工业园区骨干网）。
    eComTEnd
};
```
