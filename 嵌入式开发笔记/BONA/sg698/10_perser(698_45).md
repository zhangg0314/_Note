## 2.RCSD解析处理

1. 通过0x6012任务配置的属性3读取
2. 通过0x500*冻结数据标识直接读取

```
如果RCSD没传值：
	1.任务配置表直接返回错误码7
	2.当无OAD时，RCSD=0，即SEQUENCE OF的数据项个数为0，表示全选。通过读取冻结数据类的属性3获取,获取的都是OAD
	3.通过读取冻结数据类的属性3获取的oad直接转为ROAD的相关联属性，ROAD的oad值为冻结数据类标识符0x500*
如果RCSD没有ROAD：
	    if (oi == 0x6012)
        {
            csd.road.oad.oi = 0x5000; //实时数据
        }
        else
        {
            csd.road.oad.oi = oi;     //0x5000*
        }
     直接把oad的值转为ROAD的相关联属性，冻结数据类ROAD的oad值为冻结数据类标识符0x500*，任务配置类直接当实时数据读
如果RCSD存在ROAD
	不用处理，主站传啥用啥
```
