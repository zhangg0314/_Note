# 整体架构

集中器（concentrator）是电力采集系统的核心终端，向上连主站，向下连采集器/电表。

```
主站 (Master Station)
   │
   │ 上行：无线为主，有线备用
   ▼
集中器 (Concentrator)
   │
   │ 下行：RS-485 / 红外 / 级联
   ▼
采集器 → 电表
```

# 上行无线通道

## 1. GPRS / 2G·3G / 4G 公网

- 目录：`pppd/`、`dial.sh`、`gprs.cpp`、`usbethdial/`、`config/options`
- 原理
  用运营商公网回传数据。终端插 SIM 卡，拨号建立 PPP 连接 → 拿到 IP → 走 TCP/UDP 上主站。
- 三代拨号方式：
  - **2G/3G GPRS**：串口接模块，`AT` 命令拨号，PPP 封装 IP。经典 `pppd` + `chat`/`dial` 脚本。
  - **4G LTE**：模块出虚拟网卡（USB RNDIS/ECM），`usbethdial` 用 AT 命令控制，系统当普通网卡用。
- 特点：成本低、覆盖广、带宽高；但走公网，安全靠应用层加密（`libzip` 的 AES）。

### 2. GSM 07.10 多路复用（Mux）

- 目录：`gsmmux/gsm0710.c`
- 原理：GSM 模块只有一根串口，却要同时发数据、收短信、查信号、拨号。GSM 07.10 把这一根物理串口虚拟成多条逻辑通道（DLC），每条独立收发，互不干扰——类似「串口版时分复用」。
- 帧格式：flag(0xF9) + 地址字节 + 控制字节 + 长度 + 数据 + FCS 校验。

### 3. SMS 短信通道

- 目录：`libsms/`、`sms_pdu.cpp`
- 原理：用 GSM 短信做通信载体，不是 IP。集中器把数据编成 PDU 短信发给主站，主站回短信下发命令。
- 特点：信号差也能通（走信令信道），但窄、慢、贵，通常做**备用通道 / 应急控制 / 报警**。
- PDU 内容：编码方式（7bit/8bit/UCS2）、服务中心号码、用户数据长度等。

### 4. 230MHz 无线专网

- 目录：`linkmsgd/Wireless230M.cpp`
- 原理：电力专用频段 230MHz，自建无线数传电台。主站架大电台，集中器带小电台，点对点或轮询组网。
- 特点：与公网相反——专网、不依赖运营商、实时性高、安全可控；但带宽极低（几十 kbps 级）、需自建基站、覆盖受地形影响。

## 三、本地 / 近距通道

### 5. 红外（Infrared）

- 目录：`infrared/IrSerMan.cpp`、`irsev.cpp`、`serialsev.cpp`
- 原理：掌机/手持设备用红外近距和集中器通信，做现场维护、参数抄读、本地调试。底层走串口，红外只当物理介质。
- 特点：免接线免接触，距离近（米级）、需对准。

### 6. 级联（Cascade / RS-485）

- 目录：`cascade/jilian.cpp`（代码内叫 `SeriesAlly`，即「串联/级联」）
- 原理：集中器 → 采集器 → 电表的下行通信，通常 RS-485 总线，一主多从轮询。
- 详见下文《级联是什么》。

---

## 四、有线备用

### 7. 以太网 TCP/UDP

- 目录：`linkmsgd/TcpClientHost.cpp`、`UdpClient.cpp`
- 原理：集中器带网口，直接插网线走 TCP/UDP 上主站。协议栈同 GPRS 那套 IP，只是物理介质换成有线。
- `UdpClient` 常做心跳/广播发现，`TcpClient` 做正式数据通道。

## 六、各通道一句话对比

| 通道 | 物理介质 | 带宽 | 依赖运营商 | 用途 |

## 七、级联是什么

### 词义

「级」= 层级/档次，「联」= 连接。字面：**一级接一级，串成链**。

### 原理

通信里，级联 = 设备不都直接挂主设备，而是**一层套一层往下串**：

```
主站
 └─ 集中器（一级）
     └─ 采集器（二级）   ← 级联下来的
         └─ 电表（三级） ← 再级联下来
```

集中器不直接连每个电表，RS-485 口、地址空间都有限。所以中间插采集器：集中器管几个采集器，每个采集器再管一片电表。数据一层层往上汇总。

### 为什么叫级联（对比并联）

- **星型（并联）**：主设备一根线直连每个从设备，大家平级。

```
        主站
       / | \
      表 表 表
```

- **级联（串联）**：从设备不并列，而是串成串。A 挂主站，B 挂 A，C 挂 B。像糖葫芦、链条。

```
主站 → A → B → C
```

每一「级」只跟它上下两级打交道，不越级。所以叫**级联**。

### 本项目中的实现

代码 `S_SERIES_ALLY_PARAM` 结构，`isValidAddr` 判断地址是否为「级联终端地址」：

- 有主地址（`mainAddr`）+ 最多 3 个下级终端地址（`subsAddr[4]`）。
- 一台集中器能级联下面最多 3 台采集终端。
- 按周期轮询（`Cycle` 巡测），超时重发（`ResendTime`）。

一句话：**级联 = 主设备不直达末端，靠中间设备一级级接力转发下去。**
