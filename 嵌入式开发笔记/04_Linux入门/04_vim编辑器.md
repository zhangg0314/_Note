# 移动

## 1.上下左右

```bash
h j k l
#分别为左移一个字符，下移一行，上移一行，右移一个字符
```

## 2.行内移动

```bash
 w	#向后一个单词
 b	#向前一个单词
 0	#行首    
 ^	#行首非空白字符 
 $	#行尾
```

## 3.行间移动

```bash
gg	#文件首部
G	#文件尾部

数字n  gg或者G #移动到第n行 

gg=G#对齐缩进全文

=	#对齐缩进当前光标所在行，也可以缩进选中的多行
```

4.页间移动

```bash
ctrl+b	#向上翻页   

ctrl+f（forword）#向后翻页

H M L
#直接瞬移到文件的头 中 尾
```

# 复制删除剪切

## 1.单个字符

```bash
x #剪切一个字符
```

## 2.多行内容

```bash
[n] dd #剪切n行  
[n] yy #复制n行
[n] x  #剪切n个字符
```

## 3.复制粘贴

```bash
p     #用于vim编辑器内部之间的粘贴
        
shift + insert  #xshell专用复制粘贴
        
ctr+shift+v#用于外部的ctr+c复制过来的粘贴到vim编辑器内部

y或者d 0  #复制或者剪切光标处到行首的那一部分

y或者d $  #复制或者剪切光标处到行尾的那一部分


:n,m d或者y  #底行模式--操作一个块
    
d w        #删除一个单词：
```

# 查找替换

```bash
#替换：
   	   r #替换一个字符 
       R #进入替换模式，可以猛猛替换
#查找：
		/str #查找str，n高亮显示下一个，N显示上一个
		:n,m s/str/det_str/g #（确认替换）全部替换
         :% s/str/des_str/g  #全文替换
```

# 分屏命令

```bash
:sp [文件名]  #横向分屏
:vsp [文件名] #竖向分屏

Ctrl+h j k l #移动到哪个窗口
```

# 行号显示

```bash
	:setnu  #设置行号  
     :setnonu #取消行号
```

# 定位行号

```bash
         vi 文件名 +n #打开已有文件，并且光标初始在第n行的位置
         :n   #光标定位到第n行//好处在于，在几千行的代码中只需要一个命令就能直接定位，而不需要鼠标慢慢的滑
```

# 文件保存

```bash
          :q #退出
          :w #保存
          :q！#不保存修改的内容直接退出
          :w file #另存为文件file
          :r file #读取file文件内容到光标处
```

# 可视模式

```bash
       v #进入可视模式，可以用上下左右选中

```
