# 以太网概述

以太网（Ethernet）是当今最广泛的局域网技术标准，由IEEE 802.3定义。在嵌入式领域，以太网常用于设备联网、远程通信、数据采集等场景。

# MAC与PHY

## 1.概念

以太网通信的核心由两部分组成：

- **MAC（Media Access Control）**：媒体访问控制层，属于OSI数据链路层的下半部分。负责数据帧的封装/解封、CRC校验、冲突检测（CSMA/CD）等。通常集成在MCU或SoC内部。
- **PHY（Physical Layer）**：物理层，负责将数字信号转换为可在网线上传输的模拟信号（电平转换、编码、时钟恢复等）。通常是独立芯片（如LAN8720、RTL8201），也有集成在SoC中的。

## 2.MAC与PHY的关系

```
MCU/SoC                     外部
┌─────────────┐    ┌─────────┐    ┌──────────┐
│  CPU        │    │  MAC    │    │   PHY    │──── 网线
│  应用程序    │───>│ 控制器   │───>│ 物理层   │
│             │    │         │    │  芯片    │
└─────────────┘    └─────────┘    └──────────┘
                   (芯片内部)      (通常外接)
```

- MAC通过MII/RMII等接口与PHY连接
- PHY通过RJ45接口连接网线
- MAC和PHY之间传输的是数字信号，PHY和网线之间传输的是模拟信号

# MII/RMII接口

MAC与PHY之间通过标准接口通信，常见接口：

| 接口 | 数据线宽度 | 引脚数 | 时钟频率 | 特点 |
|------|-----------|--------|---------|------|
| MII | 4bit | 18 | 25MHz | 标准接口，引脚多 |
| RMII | 2bit | 9 | 50MHz | 精简接口，引脚少，常用 |
| GMII | 8bit | 24 | 125MHz | 千兆以太网 |
| RGMII | 4bit | 12 | 125MHz | 精简千兆接口 |

RMII接口信号说明：
- `TXD[1:0]`：发送数据（2bit）
- `RXD[1:0]`：接收数据（2bit）
- `TX_EN`：发送使能
- `RX_DV`：接收数据有效
- `REF_CLK`：50MHz参考时钟
- `CRS_DV`：载波侦听/接收数据有效（RMII复用）

# 以太网帧格式

## 1.IEEE 802.3标准帧

```
┌──────────┬──────────┬──────────┬──────────┬──────────┬──────────┬─────────┐
│ 前导码    │ 目的MAC  │ 源MAC    │ 类型/长度 │  数据    │  填充    │  FCS    │
│ (8字节)   │ (6字节)  │ (6字节)  │ (2字节)   │(46~1500) │ (0~46)  │ (4字节) │
└──────────┴──────────┴──────────┴──────────┴──────────┴──────────┴─────────┘
```

- **前导码**：7字节`10101010` + 1字节`10101011`，用于时钟同步
- **目的MAC/源MAC**：6字节MAC地址，如`AA:BB:CC:DD:EE:FF`
- **类型/长度**：值>1536表示类型（如0x0800=IPv4，0x0806=ARP），否则表示数据长度
- **数据**：有效载荷，最少46字节（不足需填充），最多1500字节
- **FCS**：CRC32校验码，由MAC硬件自动计算

## 2.帧长度

- 最小帧长：64字节（不含前导码）
- 最大帧长：1518字节（不含前导码）
- 超过1500字节为巨型帧（Jumbo Frame），非标准

# MAC地址

- 48位（6字节），通常表示为`XX:XX:XX:XX:XX:XX`
- 前3字节为OUI（厂商标识），由IEEE分配
- 后3字节为设备标识，由厂商自行分配
- `FF:FF:FF:FF:FF:FF`为广播地址
- 第一字节最低位为0表示单播，为1表示组播

# 嵌入式以太网开发要点

## 1.硬件连接

- MCU的MAC接口（MII/RMII）连接PHY芯片
- PHY芯片通过变压器（网络变压器/磁珠）连接RJ45座
- 需要25MHz或50MHz晶振为PHY提供参考时钟
- MDIO/MDC总线用于MCU配置PHY寄存器

## 2.常见PHY芯片

| 芯片 | 厂商 | 速率 | 接口 | 特点 |
|------|------|------|------|------|
| LAN8720 | Microchip | 10/100M | RMII | 低功耗，常用 |
| RTL8201 | Realtek | 10/100M | MII/RMII | 性价比高 |
| DP83848 | TI | 10/100M | MII/RMII | 工业级 |
| KSZ8081 | Microchip | 10/100M | RMII | 集成变压器驱动 |

## 3.软件协议栈

嵌入式以太网开发通常需要协议栈：
- **LwIP**：轻量级IP协议栈，适合资源受限的MCU
- **FreeRTOS+TCP**：配合FreeRTOS使用
- **Zephyr网络栈**：Zephyr RTOS内置
