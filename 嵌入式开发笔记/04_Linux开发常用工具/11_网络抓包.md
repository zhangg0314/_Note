# 命令行方式

## 1.`tcpdump`

### 1.介绍

`tcpdump` 是 Linux 下功能强大的命令行抓包工具，支持过滤规则，可直接查看包内容。

### 2.基本用法

```bash
# 捕获所有网络接口的数据包（需要root权限）
sudo tcpdump -i any

# 捕获指定接口（如eth0）的数据包
sudo tcpdump -i eth0

# 捕获指定数量的包（如10个）后退出
sudo tcpdump -i eth0 -c 10

# 保存捕获的包到文件（后续可用Wireshark分析）
sudo tcpdump -i eth0 -w capture.pcap

# 读取保存的包文件并显示内容
tcpdump -r capture.pcap
```

### 3.显示包内容

```bash
# 以ASCII码显示包内容（-A）
sudo tcpdump -i eth0 -A

# 以十六进制和ASCII码显示包内容（-X）
sudo tcpdump -i eth0 -X

# 显示更详细的协议信息（-v 或 -vv 或 -vvv）
sudo tcpdump -i eth0 -vvv -X
```

### 4.过滤规则

```bash
# 捕获特定端口（如80端口）的包并显示内容
sudo tcpdump -i eth0 port 80 -X

# 捕获特定IP（如192.168.1.100）的包并显示内容
sudo tcpdump -i eth0 host 192.168.1.100 -A

# 捕获TCP协议且目标端口为443的包
sudo tcpdump -i eth0 tcp dst port 443 -vvv -X
```

## 2.`tshark`（`wireshark` 的命令行版本）

### 1.介绍

`tshark` 是 `wireshark` 的命令行工具，功能类似 `tcpdump` 但支持更多协议解析。

### 2.基本用法

```bash
# 捕获eth0接口的包并显示详细内容
sudo tshark -i eth0

# 以JSON格式显示包内容（便于解析）
sudo tshark -i eth0 -T json

# 显示HTTP请求的URL和内容
sudo tshark -i eth0 -Y "http.request" -T fields -e http.request.uri -e http.file_data
```

### 3.显示应用层内容

```bash
# 显示发送的ASCII文本数据
sudo tshark -i eth0 -Y 'tcp.dstport == 8080 and ip.dst == 192.168.1.100' -T fields -e data.text
#如 Hello, Server! This is a test message.
# 显示十六进制数据
sudo tshark -i eth0 -Y 'tcp.dstport == 8080 and ip.dst == 192.168.1.100' -T fields -e data
#如68 3a 00 43 05 06 05 04 03 02 01 10 e0 d4 09 07 00 f2 09 02 00 03 02 08 01 00 00 78 00 64 19 68 01 00 15 08 25 20 68 14 0d 33 33 38 37 35 33 33 33 34 33 33 33 35 f9 16 00 4b d1 16
```
