# AES-128 加密流程详解

> 基于 Gurux DLMS 库 `CGXCipher::Aes1Encrypt` 源码逐行分析。标准流程 + 代码简化推导。

---

## 一、输入与数据布局

| 参数 | 大小 | 说明 |
|:--|:--|:--|
| 明文 | 16 字节 | 一个 AES 块 |
| 原始密钥 K₀ | 16 字节 | 128-bit 密钥 |

16 字节按**列优先**填成 4×4 矩阵：

```
输入: d₀ d₁ d₂ d₃ | d₄ d₅ d₆ d₇ | d₈ d₉ d₁₀ d₁₁ | d₁₂ d₁₃ d₁₄ d₁₅

矩阵:
       ┌                    ┐
       │ d₀   d₄   d₈   d₁₂ │  第 0 行
       │ d₁   d₅   d₉   d₁₃ │  第 1 行
       │ d₂   d₆   d₁₀  d₁₄ │  第 2 行
       │ d₃   d₇   d₁₁  d₁₅ │  第 3 行
       └                    ┘
       列 0  列 1  列 2  列 3

密钥同样排列:
       ┌                    ┐
       │ k₀   k₄   k₈   k₁₂ │
       │ k₁   k₅   k₉   k₁₃ │
       │ k₂   k₆   k₁₀  k₁₄ │
       │ k₃   k₇   k₁₁  k₁₅ │
       └                    ┘
```

## 二、初始轮 — AddRoundKey(K₀)

**标准步骤**（逐字节 XOR 初始密钥）：

```
data[i] = data[i] ⊕ K₀[i]     (i = 0..15)
```

---

## 三、主循环 9 轮（Round 1~9）

每轮四个操作。代码中 SubBytes 与 AddRoundKey 合并执行。

### 3.1 SubBytes + AddRoundKey（代码合并实现）

**标准做法（两步）**：

```
Step A: data[i] = data[i] ⊕ key[i]       // AddRoundKey（用当前轮密钥 Kₙ）
Step B: data[i] = S_BOX[data[i]]          // SubBytes（查 S 盒替换）
```

**代码简化（一步）**：

```c
data[i] = S_BOX[data[i] ^ key[i]];
```

> XOR 后再查表，与先查表再 XOR 逻辑等价。少一次写回。轮 1 用 K₁，轮 2 用 K₂……每轮的 key 是上一轮末尾 KeyExpansion 新生成的。

### 3.2 S-Box 原理

S-Box 是一个 256 条目的固定替换表，由两步生成：

```
S(x) = AffineTransform( x⁻¹ )

x⁻¹ = x 在 GF(2⁸) 上的乘法逆元（x=0 则取 0）
AffineTransform = 8×8 矩阵乘 + XOR 常数 0x63
```

GF(2⁸) 不可约多项式：`x⁸ + x⁴ + x³ + x + 1`。

S 盒提供了非线性——阻断线性/差分密码分析。AES 全球同一张 S 盒。

前 16 个值：`63 7C 77 7B F2 6B 6F C5 30 01 67 2B FE D7 AB 76 ...`

### 3.3 ShiftRows（行移位）

**标准步骤**：

```
第 0 行：不移 —————————————————————————————→ 不动
第 1 行：左移 1 列       d₁→d₁₃, d₅→d₁, d₉→d₅, d₁₃→d₉
第 2 行：左移 2 列       d₂↔d₁₀, d₆↔d₁₄
第 3 行：左移 3 列       ─ 等价于右移 1 列
```

代码：

```c
// 第 1 行：左移 1
buf1 = data[1]; data[1] = data[5]; data[5] = data[9];
data[9] = data[13]; data[13] = buf1;

// 第 2 行：左移 2（交换两对）
buf1 = data[2]; buf2 = data[6];
data[2] = data[10]; data[6] = data[14];
data[10] = buf1; data[14] = buf2;

// 第 3 行：左移 3 = 右移 1
buf1 = data[15]; data[15] = data[11];
data[11] = data[7]; data[7] = data[3];
data[3] = buf1;
```

图解：

```
移位前:            移位后:
┌           ┐    ┌           ┐
│ a₀ a₄ a₈ a₁₂│    │ a₀ a₄ a₈ a₁₂│  ← 不动
│ a₁ a₅ a₉ a₁₃│    │ a₅ a₉ a₁₃ a₁│  ← 左移 1
│ a₂ a₆ a₁₀ a₁₄│    │ a₁₀ a₁₄ a₂ a₆│  ← 左移 2
│ a₃ a₇ a₁₁ a₁₅│    │ a₁₅ a₃ a₇ a₁₁│  ← 左移 3
└           ┘    └           ┘
```

目的：每列字节来自上一轮不同列——扩散。

### 3.4 MixColumns（列混合）

**标准公式**（GF(2⁸) 上矩阵乘）：

```
┌        ┐   ┌              ┐ ┌     ┐
│ 新 d₀  │   │ 2  3  1  1   │ │ d₀  │
│ 新 d₁  │ = │ 1  2  3  1   │×│ d₁  │
│ 新 d₂  │   │ 1  1  2  3   │ │ d₂  │
│ 新 d₃  │   │ 3  1  1  2   │ │ d₃  │
└        ┘   └              ┘ └     ┘
```

展开：

```
新 d₀ = 2d₀ ⊕ 3d₁ ⊕ 1d₂ ⊕ 1d₃
新 d₁ = 1d₀ ⊕ 2d₁ ⊕ 3d₂ ⊕ 1d₃
新 d₂ = 1d₀ ⊕ 1d₁ ⊕ 2d₂ ⊕ 3d₃
新 d₃ = 3d₀ ⊕ 1d₁ ⊕ 1d₂ ⊕ 2d₃
```

> GF(2⁸) 上：加法 = XOR，`2x = GaloisMultiply(x)`，`3x = x ⊕ 2x`。

**代码简化推导**：

先算公共项：

```c
col_sum = d₀ ^ d₁ ^ d₂ ^ d₃     // 整列 XOR
```

以新 d₀ 为例：

```
代码: tmp = GaloisMultiply(d₀ ⊕ d₁)         // = 2d₀ ⊕ 2d₁ ↖ 一次乘法得两个 2×
      新 d₀ = d₀ ⊕ tmp ⊕ col_sum
           = d₀ ⊕ (2d₀ ⊕ 2d₁) ⊕ (d₀ ⊕ d₁ ⊕ d₂ ⊕ d₃)
           = (d₀ ⊕ d₀) ⊕ 2d₀ ⊕ (2d₁ ⊕ d₁) ⊕ d₂ ⊕ d₃
           = 0 ⊕ 2d₀ ⊕ 3d₁ ⊕ d₂ ⊕ d₃
           = 2d₀ ⊕ 3d₁ ⊕ d₂ ⊕ d₃  ✅  与标准一致
```

其余三行同理，配对 `(d₁,d₂)` `(d₂,d₃)` `(d₃,d₀)` 各做一次 GaloisMultiply。

**优化效果**：

| | 标准做法 | 代码简化 |
|:--|:--|:--|
| GaloisMultiply 次数 | 8 次/列 | **4 次/列** |
| XOR 次数 | 少 | 多几个（XOR 极廉价） |

**GaloisMultiply 实现**：GF(2⁸) 上 ×2 = 左移 1 位，若溢出（最高位=1）则 XOR `0x1B`。

```c
unsigned char GaloisMultiply(unsigned char x) {
    return (x << 1) ^ ((x & 0x80) ? 0x1B : 0);
}
```

## 四、末轮（Round 10）

SubBytes + ShiftRows + AddRoundKey。**无 MixColumns**。

---

## 五、KeyExpansion — 生成下一轮密钥

每轮结束后从当前 Kₙ 派生 Kₙ₊₁。

### 5.1 标准步骤

密钥也按 4×4 列分为 W₀ W₁ W₂ W₃（每列 4 字节）：

```
W₀_new = W₀ ⊕ SubWord(RotWord(W₃)) ⊕ RCON[round]
W₁_new = W₁ ⊕ W₀_new
W₂_new = W₂ ⊕ W₁_new
W₃_new = W₃ ⊕ W₂_new
```

图解：

```
Kₙ:    ┌──────┬──────┬──────┬──────┐
       │  W₀  │  W₁  │  W₂  │  W₃  │
       └──┬───┴──┬───┴──┬───┴──────┘
          │      │      │      │
Kₙ₊₁:    ▼      ▼      ▼      ▼
       ┌──────┬──────┬──────┬──────┐
       │ W₀'  │ W₁'  │ W₂'  │ W₃'  │
       └──────┴──────┴──────┴──────┘

W₀' = W₀ ⊕ SubWord(RotWord(W₃)) ⊕ RCON      ← 只有这列做特殊处理
W₁' = W₁ ⊕ W₀'
W₂' = W₂ ⊕ W₁'
W₃' = W₃ ⊕ W₂'
```

### 5.2 RotWord

```
W₃ = [k₁₂, k₁₃, k₁₄, k₁₅]
RotWord(W₃) = [k₁₃, k₁₄, k₁₅, k₁₂]     ← 向上旋转一个位置
```

### 5.3 SubWord

```
每个字节查 S-Box:  SubWord[w₀,w₁,w₂,w₃] = [S(w₀), S(w₁), S(w₂), S(w₃)]
```

### 5.4 RCON 轮常数

```
round 0: 0x01     round 4: 0x10     round 8: 0x1B
round 1: 0x02     round 5: 0x20     round 9: 0x36
round 2: 0x04     round 6: 0x40
round 3: 0x08     round 7: 0x80
```

**RCON 的作用**：破坏对称性。若不 XOR RCON，密钥扩展的不同轮次可能产生相同子密钥。

### 5.5 代码实现

```c
// Step A: RotWord (隐式) + SubWord + RCON + XOR W₀ → W₀_new
key[0] = S_BOX[key[13]] ^ key[0] ^ R_CON[round];  // key[13]=原W₃[1]→RotWord→W₃[0]
key[1] = S_BOX[key[14]] ^ key[1];                  // key[14]=原W₃[2]→RotWord→W₃[1]
key[2] = S_BOX[key[15]] ^ key[2];                  // key[15]=原W₃[3]→RotWord→W₃[2]
key[3] = S_BOX[key[12]] ^ key[3];                  // key[12]=原W₃[0]→RotWord→W₃[3]

// Step B: 后 3 列直接 XOR 左邻新列
for (i = 4; i < 16; i++)
    key[i] = key[i] ^ key[i - 4];
```

> RotWord 没显式旋转，直接用旋转后的下标 `key[13,14,15,12]` 访问。等价，省临时变量。

## 六、完整轮次结构

```
         明文 16B
           │
     AddRoundKey(K₀)           ← 初始
           │
     ┌─────────────────────┐
     │ SubBytes + AddRoundKey │  合并为 S_BOX[data ^ key]
     │ ShiftRows            │
     │ MixColumns           │  × 9 轮 (Round 1~9)
     │ KeyExpansion → Kₙ₊₁ │
     └─────────────────────┘
           │
     SubBytes + AddRoundKey    ← 末轮 Round 10（无 MixColumns）
     ShiftRows
           │
         密文 16B
```

| 轮 | SubBytes | ShiftRows | MixColumns | AddRoundKey | KeyExpansion |
|:--|:--|:--|:--|:--|:--|
| Init | — | — | — | K₀ | — |
| 1~9 | ✅ | ✅ | ✅ | K₁~K₉ | ✅→K₂~K₁₀ |
| Final(10) | ✅ | ✅ | ❌ | K₁₀ | — |

---

## 七、代码中的四个简化总结

| 简化 | 标准做法 | 代码做法 | 递推 |
|:--|:--|:--|:--|
| AddRoundKey + SubBytes 合并 | 分两步做 | `S_BOX[data ^ key]` | XOR 和查表顺序可互换 |
| MixColumns 用 col_sum | 每行独立展开 `2d₀⊕3d₁⊕d₂⊕d₃` | `d₀⊕G(d₀⊕d₁)⊕col_sum` | XOR 结合律展开消去 |
| GaloisMultiply 减半 | 每列 8 次 | 4 次，XOR 邻居配对 | 用廉价 XOR 换昂贵乘法 |
| RotWord 隐式 | 显式旋转数组再访问 | 直接 `key[13,14,15,12]` | 下标等价 |
