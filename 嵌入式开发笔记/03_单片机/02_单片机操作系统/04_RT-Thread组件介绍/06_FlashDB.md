# 整体架构框图

```plaintext
┌─────────────────────────────────────────────────────────────────┐
│                        FlashDB (闪存数据库)                     │
│  向上API：fdb_kv_set/get/delete、fdb_ts_add/read、fdb_blob_*     │
│  向下调用：FAL的分区读/写/擦除接口                              │
└───────────────────────────┬─────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────────┐
│                            FAL (Flash抽象层)                    │
│  向上API：fal_partition_read/write/erase、fal_partition_find     │
│  向下调用：SFUD的SPI Flash操作接口 + RT-Thread设备驱动接口       │
└───────────────────────────┬─────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────────┐
│                         SFUD (SPI Flash通用驱动)                │
│  向上API：sfud_read/write/erase、sfud_device_find、sfud_get_info │
│  向下调用：RT-Thread SPI设备驱动接口（spi_transfer等）           │
└───────────────────────────┬─────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────────┐
│                 RT-Thread 设备驱动层 (SPI/Flash)                │
│  向上API：rt_spi_transfer、rt_device_read/write、rt_device_find  │
│  向下调用：AT32F40XXX寄存器库的SPI/Flash底层操作函数            │
└───────────────────────────┬─────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────────┐
│            AT32F40XXX 寄存器库 (HAL/LL库)                       │
│  向上API：at32_spi_send_recv、at32_flash_erase_page             │
│  向下调用：直接操作AT32F40XXX硬件寄存器（SPIx/FLASHx）          │
└───────────────────────────┬─────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────────┐
│                  AT32F40XXX 硬件 (SPI外设 + W25Qxx Flash)       │
└─────────────────────────────────────────────────────────────────┘
```
